# Семейная Змейка: Android-клиент и локальные доказательства

## Поведение

В каталоге Змейки доступен семейный режим: выбор участника, явное приглашение,
принятие и общее поле. У каждого игрока своя змейка, еда и счёт общие.
Начало и продолжение требуют готовности обоих. Отключение игрока останавливает
партию; возвращение не запускает её без нового подтверждения готовности.

`SnakeOnlineActivity/View` показывают только подтверждённые сервером клетки.
Интерполяция между ними не вычисляет будущие ходы. Уход в фон закрывает отдельный
игровой канал и его callbacks. Рабочий канал мониторинга не используется.

`SnakeRealtimeBridge` подключается к `/family-games` с собственным Socket.IO
соединением. Credentials выдаёт адаптер текущего владельца профиля каждого
клиента, после проверки server capabilities. Изменение семьи/профиля блокирует
старые credentials; TLS-настройки сохраняются в отдельном OkHttp клиенте.
Повороты имеют epoch/sequence/targetTick, кратковременный повтор сохраняет
одинаковое тело. Очередь учитывает два уже принятых будущих поворота; старые
команды не попадают в новую эпоху и не сохраняются в HTTP outbox.

телефонов, локальный сервер остановлен.

Исходные native failures сохранены: у тестового manifest не было INTERNET,
а Samsung lifecycle assertion проверял `finish()` до завершения onPause.
Исправлены разрешение isolated APK и bounded проверка фактического закрытия.

## Границы доказательств

Основные APK, OTA и VPS этим этапом не опубликованы. Для рабочей семейной
партии требуется серверный контракт из `snake-realtime-2026-10-11.md`; перед
выкладкой проверить единственный Node-процесс (PM2 fork), затем обновить пару
клиентов и испытать приглашение/принятие/фон/возврат с настоящими профилями.
Полный игровой polish, шрифт 200% с длинными именами и точная визуальная
траектория частых поворотов требуют следующего этапа, записанного в TODO.
