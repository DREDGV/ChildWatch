# Передача DeepSeek / Harness · 02.10.2026

Прямого канала к Harness нет; этот файл предназначен для ручной передачи. Существующие правки активности сохранены. Серверная история по дням остаётся за DeepSeek.

## Контракт активности

- `dailyUsage` содержит последний удачный снимок, включая после перезапуска детского процесса. Кэш отделён по серверу, семье и собственному устройству.
- `appUsageCollectedAt` — время удачного сбора, не очередной отправки. `appUsageStale=true` означает повтор старых данных. `usagePermissionGranted=false` означает текущий отказ разрешения, исторические данные сохраняются.
- `dailyUsage.apps[].firstUsed` и `lastForegroundAt` — необязательные времена начала первого известного интервала и окончания последнего. Старые снимки этих полей не имеют: нельзя заменять их полуночью и временем опроса.
- Серверу сохранять удачный снимок при пустом/неудачном входящем. По дням использовать интервал и часовой пояс самого снимка. Повтор накопительного снимка не суммировать с предыдущим. На новый день старые данные не объявлять сегодняшними.

## Границы правок

- Родительский `DeviceUsageActivity.kt`: выбор по времени сбора, сохранение удачного ответа между опросами, сброс при смене контекста, реальные времена.
- Детские `DeviceInfoCollector.kt` / `AppUsageTracker.kt`: постоянный кэш и новые поля.
- Карты обоих клиентов: только размещение семейных маркеров и порядок выбранного аватара; координаты точные, аватары перекрываются. Скорость/шлейф не переписаны.
- Родительский `MainActivity.kt` и layout: резерв места для адреса, отсутствие повторного сброса адреса/перезапуска опроса при обновлении того же человека.
- `DatabaseManager.confirmOwnProvisionalFamilyMembership`: запоздавший повтор настройки сохраняет уже явно подтверждённое имя/аватар. Регрессия `profile-confirmation-replay.test.js` прошла на SQLite в памяти. Это найденный путь перезаписи, источник конкретного сброса Бабы Саши по рабочим журналам не подтверждён.
- Release/deploy scripts: контроль возрастания версии, пакета/подписи и исправление экранирования запуска. Существующий опубликованный сервер не менялся.
