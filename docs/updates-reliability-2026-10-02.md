# Надёжное обнаружение обновлений · 02.10.2026

## Исправленные причины

- Детский пакет ru.example.parentwatch.debug выбирал родительскую запись manifest и отвергал её. Теперь ключ учитывает .debug, а запись под подсказанным ключом принимается только при совпадении packageName; иначе ищется соответствующий пакет в остальных записях.
- «Позже» скрывало один выпуск бессрочно. Теперь отсрочка — 24 часа, сохранённый manifest остаётся; ручная проверка показывает выпуск и во время отсрочки. Старое бессрочное скрытие без даты больше не блокирует предложение.
- Интервал 15 минут применялся только при запуске/возврате. Контроллер раз в минуту при RESUMED проверяет необходимость запроса; успешные запросы ограничены 15 минутами, сбой не записывается как успех. При уходе в фон периодический цикл останавливается.
- Кеш предложения/успешного запроса/отсрочки привязан к нормализованному адресу сервера. Смена сервера очищает только эти значения, а запоздалый ответ не отображается. Кнопка и подтверждение скачивания проверяют тот же адрес.
- Ручная проверка во время автоматической ставится в одну очередь вместо молчаливого отказа; повторные нажатия не создают очередь из многих запросов.
- Перевод системного времени назад не продлевает ограничения проверки/отсрочки. Запрос manifest просит revalidation через Cache-Control: no-cache.

## Границы

Новые изменения пока только в исходниках, не в установленной 7.4.273. Серверный агент может независимо публиковать её и серверные исправления. Проверки подписи, SHA256, размера, packageName и versionCode установщика не ослаблены. Без опубликованного выпуска с большим versionCode предложение закономерно отсутствует. Фоновая тихая установка не обещается: подтверждение Android сохраняется.

Реальные сетевые сбои, суточная отсрочка, возврат из настроек установки и установка нового APK через интерфейс остаются runtime-проверкой. Нового внешнего оформления в этом этапе нет: используется существующий индикатор/панель главного экрана.
