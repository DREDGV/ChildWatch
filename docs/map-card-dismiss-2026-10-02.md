# CW-06 · Закрытие сведений на карте · 02.10.2026

Владелец сообщил, что окна после нажатия аватара трудно убрать, и попросил сохранить основную карту свободной от лишних панелей.

Подтверждено исходниками: ParentMonitor не имел явной кнопки закрытия карточки; ChildDevice имел кнопку 40dp. Фоновая повторная привязка выбранного семейного участника в обоих клиентах снова выставляла VISIBLE. В ChildDevice связанный маркер открывал одновременно InfoWindow и карточку.

В обеих DualLocationMapActivity закрытие прячет карточку/подробности, закрывает InfoWindow маркеров и сохраняет флаг до явного выбора. Касание карты не поглощает жест; новое нажатие маркера/участника снова открывает карточку, фоновый вызов с centerMap=false — нет. Back сначала закрывает сведения, следующий Back идёт обычным путём. Начальное состояние карточки скрыто. Выбранный человек, линии, сеть и передача координат не сбрасываются. Убрано дублирование popup связанного маркера в ChildDevice.

В обоих activity_dual_location_map.xml кнопка закрытия 48dp с «Скрыть сведения». Для ParentMonitor добавлен map_card_dismiss.xml. Новых экранов/цветов/Room-изменений нет.

План map-next-stage-2026-10-02.md дополнен требованиями: текущая карта по умолчанию, развёрнутая/компактная/скрытая панель истории, явное повторное открытие, пауза воспроизведения при скрытии, отсутствие автоматического открытия при обновлении.

В демонстрационном map-day-proposal.html эти состояния реализованы. Browser-проверка: после загрузки «Сейчас» и свободная карта; история → Свернуть оставляет время и две кнопки; Скрыть оставляет «Показать историю»; повторное открытие сохраняет компактное состояние. Screenshot map-day-proposal-collapsed.jpg, ширина 390. Макет вымышленный и не подтверждает Android-исправление.

Проверки исходников: три XML разобраны; git diff --check PASS. Компиляция/тесты/установка/реальная Android-отрисовка не проводились по сохранённому ограничению. Сценарий следующей разрешённой проверки: аватар → крестик → несколько live-обновлений → карточка не появляется; повторный аватар → карта/Back → закрытие; следующий Back выходит; отдельный popup исторической точки также закрывается.
