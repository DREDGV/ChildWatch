# Измеренная скорость семейной карты · 01.10.2026

## Сквозной путь

LocationMotion получает скорость только при hasSpeed; точность только при API ≥26 и hasSpeedAccuracy. Нулевое измерение сохраняется, отсутствующее значение не заменяется нулём. Оба основных отправителя передают speedMps/speedAccuracyMps в м/с. HTTP взрослого и /api/loc ребёнка сохраняют данные вместе с конкретным временем/координатами/собственным аутентифицированным устройством.

LocationMotionStore — дополнительная таблица сервера с ключом телефон+время+координаты, индексом времени и ограничением хранения 48 часов; очистка не чаще пяти минут. Live и семейная история присоединяют только измерение той же точки. Прежние LOCATION/LOCATION_HISTORY сохранены. Необязательный сбой motion не ломает чтение координат. WebSocket взрослого передаёт новые поля, долговременный источник карты — HTTP. Прежние серверные поля speed не считаются измерением без точности.

LocationOutbox: собственная SQLite, версия 1 → 2, две nullable колонки с ADD COLUMN при обновлении, без удаления очереди. Старые точки получают null. Room не менялся. Новая история включает скорость/точность в каждом исходном измерении.

Оба клиента читают motion в live/history. MapRouteSegments.Fix расширен совместимым конструктором. MapSpeed предпочитает измеренную скорость 0–60 м/с с точностью ≤max(0.7 м/с,35% скорости), позиционная точность ≤50 м; live свежесть ≤45 секунд. В ином случае прежняя оценка смещения/неизвестное значение. Число GPS без ≈; резервное с ≈; градиент использует тот же выбор. Детская собственная локальная точка использует speed только при совпадении времени измерения.

История сообщает deviceId. Клиенты отклоняют ответ, если источник не совпадает с выбранной live-точкой; старые серверы без поля остаются совместимы. Запоздавший ответ после смены источника отбрасывается существующим guard.

## Проверено и не проверено

Node --check: LocationMotionStore.js, location.js, DatabaseManager.js, index.js, working-server.js — успешный exit 0. XML двух map_speed ресурсов разобран. Исходники отправки, парсинга, привязки точки и миграции просмотрены. Сборки/тесты/Android/реальные GPS/миграция на установленном приложении не запускались. Сервер не опубликован. Нужны новые сервер и оба приложения; старые источники сохраняют приблизительный режим.

API сверено: https://developer.android.com/reference/android/location/Location . Скорость/точность — измерения провайдера, не гарантия распознавания транспорта.
