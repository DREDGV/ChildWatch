# CW-09 · Удалённое фото · 01.10.2026

## Исходники

- Детский `PhotoCaptureService`: загрузка HTTP не зависит от сокета после съёмки; две ограниченные попытки с requestId/временем/собственным устройством. Сокет остаётся быстрым предпросмотром. Неудачный исходник не удаляется. Ограничение съёмки 30 секунд завершает callback и освобождает очередь.
- `PhotoDeliveryStore.js`, `/api/photo/result`, `/api/media/photo-result`: долговременная квитанция успеха/ошибки, повторная принятая загрузка возвращает уже сохранённый файл. Квитанция и photo_files пишутся двумя операциями: атомарность при падении между ними не доказана; очистка накопленных квитанций не реализована.
- Сервер проверяет роль ребёнка/REMOTE_PHOTO для запроса, галереи, скачивания и миниатюры. Явного адресата нельзя заменить единственным подключённым ребёнком. Таймер сервера отсчитывается от первоначального запроса, ACK не продлевает ожидание.
- ParentMonitor: HTTP-получение по requestId с общим двухминутным пределом, отсечение старых ответов, восстановление ожидания/выбора после пересоздания в том же семейном контексте. Ошибка сети сохраняет галерею; HTTP 401/403 скрывает её.
- Главное окно без ScrollView: кадр по оставшейся высоте, Material-переключатель камер с иконками, четыре последних снимка. Все фото открываются в отдельной галерее по шесть с кнопками Назад/Далее, загрузкой и повтором при ошибке. Просмотр, сохранение MediaStore и отправка сохраняются.
- Верхний селектор: канонический профиль по любому активному устройству, имя/аватар вместе; scope проверяется после асинхронной загрузки. В макете убран выдуманный робот, используется явно отмеченная буква «Л»; фактический текущий аватар Лёвы не получен в этой сессии.

## Проверено / пределы

Node `--check`: index, media, PhotoDeliveryStore, DeviceAccessService, WebSocketManager — PASS. Изменённые layout/drawable/strings XML разобраны — PASS. Браузерный макет просмотрен при 390×740 и 360×640, 130%/ожидание/галерея; в компактном режиме contentHeight == clientHeight, внутренней прокрутки нет. Файл `docs/design/remote-photo-preview.jpg`.

Сборки, тесты, запуск Android, запросы настоящего семейного профиля и публикация не выполнялись по сохранённому ограничению владельца. Kotlin-компиляция, Android-дизайн и работоспособность на телефонах не доказаны. Изменения требуют обоих клиентов и сервера. Системные ограничения камеры в фоне не обходятся: запрет должен стать понятной ошибкой. Сохранение API 26–28 требует разрешения на хранилище. Очень крупный шрифт/landscape и перелистывание Android нужно проверить при следующем разрешённом этапе. Неудачные исходники и квитанции требуют ограниченного хранения отдельным следующим изменением.
