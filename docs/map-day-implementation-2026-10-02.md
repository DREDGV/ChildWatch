# CW-06 · Полный доступный день и управляемая панель

02.10.2026. Владелец разрешил следующий этап после согласования свободной карты и закрытия сведений. Реализованы исходники серверной пагинации и общей панели времени; воспроизведение и трёхмесячное хранение остаются отдельными этапами подготовленного плана.

## Реализовано

- Новый `/api/location/family/history/:memberId` использует существующую семейную авторизацию: членство, выбранный телефон этого человека, LOCATION/LOCATION_HISTORY. Проверка повторяется на каждой странице. Не заменяет короткий live-trail.
- FamilyHistoryPageStore объединяет два существующих пути координат, нормализует время, фильтрует до лимита и возвращает 1000 точек с hasMore/nextCursor. Порядок — capturedAt/source/id. Курсор связан с actor/family/member/device/from/to; сам курсор не предоставляет доступ. Поддержка текущих ограничений периода до 31 дня, без новой схемы.
- Ревизия основана на count/max ID каждой append-only таблицы в выбранном периоде. Проверяется перед/после чтения и между страницами. Поздняя вставка/очистка требует новой загрузки, не смешивает версии. Текущие пути locations/parent_locations используют INSERT; ревизия не является универсальной защитой от стороннего UPDATE старых строк.
- NetworkClient обоих клиентов проверяют HTTP, контекст, границы периода и продолжение ответа. Отказы 401/403, изменение истории 409 и сетевой сбой не превращаются в пустой день.
- Обе DualLocationMapActivity последовательно догружают страницы и показывают полученную часть. Период/выбранный человек/свой actor и телефон/сервер/поколение запроса фиксируются; смена контекста отменяет загрузку и удаляет старую историю. Новые страницы не меняют выбранное время и не возвращают камеру к live-точке.
- Общий MapHistoryPanel — немодальная нижняя панель в существующей CoordinatorLayout: время, часовой пояс телефона, точность, шкала по фактическому времени, подтверждённые участки и разрывы. Выбор времени между непрерывными измерениями показывает ближайшее измерение с его собственным временем; в разрыве/до первого/после последнего курсора нет. Интерполяция координат не добавлена.
- Сворачивание оставляет время/статус, скрытие — только кнопку возврата панели. Касание карты/Back скрывает её; следующий Back возвращает live. «Сейчас» отменяет запрос, убирает исторические линии/маркеры и возвращает текущую карту. Фоновая передача координат продолжается.
- Кнопка «События» сохраняет прежние остановки/события мест/сводку. Основной список панели — участки маршрута; события сверх первых 100 раскрываются порциями, не заменяются сотнями кнопок сразу.
- Исправлена ошибка предыдущего этапа: latest семейного trail больше не обращается к const to до объявления.

## Границы

Семейная история требует нового серверного endpoint и новых клиентов. Старый сервер сообщает ошибку, не подставляет короткий след. Если семейный участник/телефон не разрешён из текущего каталога, сохраняется прежний paired-path с явным предупреждением о 1000 точках, без обещания полного дня. Legacy-path ещё имеет прежнюю обработку отдельных серверных ошибок; не считать его равноценным новой семейной загрузке.

Клиент ограничивает один просмотр 100000 исходных точек; большой период показывает частичную историю и предлагает выбрать день. Срок хранения/20000 записей взрослого/48 часов motion не изменены; отсутствующие старые точки не восстановлены. Запросы пока используют нормализацию времени SQL без новой индексации — производительность полного дня/большой базы не доказана.

Воспроизведение не добавлено в этом этапе; ручная шкала работает независимо. Поворот/перезапуск Activity возвращает карту в live и удаляет панель; восстановление выбранного дня/времени требует следующего этапа. Часовой пояс отображается явно, выбор отдельной зоны не добавлен. Правила видимости до вступления в семью остаются по текущему серверному контракту, не расширяются специальным обходом авторизации.

## Проверки и продолжение

Node syntax обоих серверных файлов PASS; XML map_history.xml разобран; имена ресурсов MapHistoryPanel/MapHistoryDialog сверены; git diff --check PASS. Исходники запросов/DTO/отказов/смены контекста/закрытия/пагинации просмотрены. Это не тесты функциональности и не компиляция Android.

По прежнему ограничению владельца Gradle/тесты/APK/установка/публикация/нативная отрисовка не выполнялись. Последний browser-макет — лишь согласованная идея, не доказательство нового Java/Kotlin-интерфейса.

При разрешении проверки нужны >1000 точек, одинаковые timestamps на границе страниц, вставка между страницами, отказ прав после первой страницы, сетевой отказ с сохранением части, пустой день, разрыв, отмена, смена пользователя/семьи/телефона, скрытие панели и несколько live-обновлений, размер шрифта 130%. Перед публикацией нужен функциональный тест SQL/ревизии на копии и Android-компиляция.

Следующее предлагаемое развитие: управляемое воспроизведение подтверждённых участков с паузой на разрывах и сохранением дня/времени при повороте экрана.
