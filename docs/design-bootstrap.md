## Инструменты: факт, а не обещание

| Возможность | Состояние и применение |
|---|---|
| Browser/Chromium rendered verification | Доступен in-app browser; публичные референсы открыты и рассмотрены |
| Android rendered verification | Android SDK/ADB и локальный Android 14 эмулятор; сценарий подключения и скриншоты, шрифт 130% |
| Screenshot / vision | `view_image`, browser screenshot, ADB screencap; сравнивать настоящий результат |
| Figma MCP | Callable-инструментов в сессии не найдено; установленный Figma plugin/skill не означает рабочий connector |
| Refero / Mobbin MCP и Refero Skill | Не найдены среди инструментов и доступных навыков; использовать публичные источники и не заявлять методологию Refero применённой |
| shadcn MCP | Не найден, к Android-проекту не применим; проверять при появлении React/shadcn |

Новых MCP, дубликатов браузера и больших собственных дизайн-навыков не установлено. Недоступный сервис не блокирует кодовую работу: использовать предоставленные экраны/публичные реальные продукты, честно записать ограничение. Не подключать платные аккаунты и не принимать условия сервиса без отдельного действия владельца.

## Короткий вход следующего агента

TODO → DESIGN.md → нужный раздел DESIGN_REFERENCES.md → один основной навык + нужная специализированная проверка → реализация → настоящий экран → сравнение/исправление → доказательство в TODO.

Для нового существенного экрана: 5–15 кандидатов, 2–4 опоры и короткий разбор до кода. Для мелкой правки: текущий компонент, сохранённое направление и затронутый визуальный сценарий. При запрете запуска статус визуальной проверки остаётся открытым. Не публиковать документацию в сторонние сервисы автоматически, даже если навык предлагает connector.
