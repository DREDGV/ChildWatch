# Восстановление звука и отложенного фото · 02.10.2026

## Звук вокруг

- Предыдущие исправления ожидания пакетов, настоящих underruns и частичной записи PCM сохранены.
- Для восстановления используется монотонное время, независимое от изменения часов. После 60 секунд без аудио сеанс останавливается с понятным сообщением, вместо бесконечных повторов запуска.
- Возвращение пакетов сбрасывает состояние переподключения и отложенную остановку. Время первого пакета остаётся временем первого пакета, а не последнего восстановления.
- При явном запрете микрофона watchdog сохраняет объяснение причины и не заменяет его общим «переподключаемся». Проверки прав и запреты Android не обходятся.
- HTTP start ограничен callTimeout 12 секунд; отмена coroutine не превращается в обычную сетевую ошибку.

## Фото и галерея

- savedInstanceState сохраняет ожидание загрузки уже снятого фото и последний запрос поздней доставки вместе со временем; восстановление только в том же сервере/семье/выбранном человеке/собственном устройстве. Истёкший запрос не повторно снимает фото, а ограниченно ищет результат по прежнему requestId. Исходное окно поздней доставки не продлевается.
- Очередь JPEG получает клиент, привязанный к исходному серверу/семье/детскому телефону. Контекст проверяется до авторизации, перед отправкой и перед повтором после обновления токена. При смене контекста файл остаётся для штатной ограниченной очереди; чужая семья не получает его.
- Если переход страницы галереи возвращает тот же набор ID, это не объявляется новой страницей: показана причина и возможность повторить. Серверная поддержка offset остаётся необходимой.
