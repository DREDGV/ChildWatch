# Мастер семьи ChildWatch

## Зачем он нужен

В ChildWatch человек и телефон — разные сущности:

- `Family` — одна семья;
- `FamilyMember` — человек с именем, ролью и аватаром;
- `FamilyDevice` — конкретный телефон, принадлежащий человеку.

Технический `deviceId` используется только для доставки команд. Он не является именем пользователя и не должен отображаться в карте, чате, фото или прослушке.

## Основные сценарии

### Первая установка ParentMonitor

1. Взрослый вводит своё имя и название семьи.
2. Сервер создаёт семью, профиль взрослого и привязывает к нему телефон.
3. Только после ответа сервера локальный мастер считается завершённым.

### Новый человек

1. Взрослый открывает «Добавить в семью».
2. Выбирает «Новый член семьи», имя, роль и аватар.
3. Сервер выдаёт одноразовое приглашение на 15 минут.
4. На новом телефоне приглашение предварительно показывается человеку и принимается.
5. Только в момент принятия сервер создаёт профиль и привязку телефона. Непринятые приглашения не создают «пустых» пользователей.

### Второй телефон существующего человека

1. Взрослый выбирает существующего члена семьи.
2. Новый телефон принимает одноразовое приглашение.
3. Сервер добавляет устройство к существующему профилю, не создавая второго человека.

### Старые установки ChildWatch

1. Старые технические привязки показываются взрослому отдельным списком и не смешиваются с новыми людьми.
2. Взрослый задаёт человеку понятное имя, роль и аватар.
3. Сервер подтверждает профиль на месте: стабильные ID, история чата и координаты сохраняются.
4. При первом запуске мастер может безопасно подтвердить собственный взрослый профиль, но детское приложение не может самостоятельно повысить свою роль.

### Управление приглашениями

- Взрослый видит только активные, ещё не использованные приглашения.
- Любое приглашение можно отозвать; после этого старый QR-код перестаёт действовать.
- Секретный токен повторно с сервера не возвращается.

### Перенос телефона между профилями

1. Взрослый выбирает телефон и новый профиль его владельца.
2. Детский телефон можно перенести только другому ребёнку, взрослый — только взрослому.
3. Перед изменением приложение ещё раз показывает старого и нового владельца.
4. Сервер повторно проверяет права взрослого и совместимость ролей.
5. История не переписывается и не удаляется: новая привязка действует только для дальнейшей работы.

## Защита от путаницы

- ParentMonitor принимает только роли `PARENT` и `GUARDIAN`.
- ChildDevice принимает только роль `CHILD`.
- Сырой ID телефона не принимается парсером приглашений.
- Сервер хранит только SHA-256 токена; сам секрет возвращается один раз создателю.
- Приглашение одноразовое, отменяемое и ограничено по времени.
- Повторное создание приглашения тем же телефоном для того же человека отменяет предыдущее.
- Один телефон может иметь только одну активную подтверждённую привязку к человеку и не может незаметно перейти к другому профилю или в другую семью.
- Старые связи не удаляются: до завершения миграции они продолжают работать отдельно от нового каталога.

## Источник данных для функций

После настройки все экраны получают людей из серверного каталога семьи. Карта, чат, фото, прослушка и сигналы используют `memberId` как личность, а один из связанных `deviceId` — только как текущий канал связи. Локальный каталог является ограниченным офлайн-кэшем последнего подтверждённого ответа сервера.

## Что ещё потребуется перед выпуском

- ручной тест чистой установки, добавления ребёнка, второго телефона и нового взрослого на двух реальных устройствах.
