# ChildWatch: довести накопленное и развивать дальше

Утверждено владельцем 10.10.2026. Текущие статусы и конкретный шаг возобновления — только в TODO.md. Этот документ фиксирует порядок, границы и приёмку, а не вторую очередь статусов.

## Ближайший цикл: проверенный кандидат

Проблема: между готовыми исходниками и реальной работой на телефонах остаётся разрыв. Состав кандидата: существующая карта/скорость/слежение, GIF/меню файлов и участники чата. До проверки кандидата не добавлять окружение, игры, новые экраны или новые каталоговые ресурсы. Опубликованный v1 не заменять.

1. Зафиксировать исходный commit, состав и серверные требования; подготовить локальные проверки и точный пакет. Номер — штатная автонумерация после сверки опубликованных/установленных/выданных версий. Подпись и package прежние; APK downgrade, удаление приложения и сброс семейных данных запрещены.
2. Проверить чат: уже отправленная GIF/черновик/прозрачность/анимация/смайлы/отдельные файлы/закрытие/крупный шрифт. Изображение, документ, голос, offline/retry/process restart — ровно одно сообщение. Не отправлять рабочие сообщения автоматически без отдельной команды.
3. Проверить одну группу на паре телефонов: полный состав, фон, смена беседы, возврат связи; открытый чат, связь устройства и read receipt — разные признаки. Ошибка/устаревание не равны офлайн. Краткоживущая сессия может сохраняться до45сек при недоставленном выходе.
4. Карта: стоянка, ходьба, поездка; скорость у аватара, движение/follow, pan/pause/resume. Сохранить измерения с качеством и долю UNKNOWN; синтетические тесты не доказывают полевую точность.
5. Звук/фото: сохранить подтверждённое восстановление после reboot/короткого обрыва. При новом отказе собрать trace одного requestId через capture/upload/result. «Сигнал» — отдельный согласованный запрос с STOP и полной временной шкалой; таймаут экрана не починка доставки.
6. Исправлять обнаруженные ошибки в этом цикле. Невоспроизведённая причина остаётся открытой. Подготовить подписанную пару, SHA/size/cert, точный серверный пакет и backup/rollback. Сервер → клиенты → OTA; manifest атомарно последним после доступных APK. ASR остаётся OFF. Сборка кандидата, установка и публикация — раздельные согласованные действия.

## После кандидата: окружение в обоих приложениях

Добровольное локальное включение на каждом телефоне; у взрослого отдельная кнопка выбранного человека. Серверное NEARBY_SIGNALS permission/target/revocation, bounded one-shot scan/cooldown, последний snapshot TTL5мин, без истории радиосреды. Имя/тип/RSSI/давность/источники и denied/off/throttled/stale/empty явно различаются. Проверить известные Wi-Fi/Classic/BLE на Android11/14. Реальное расстояние/положение — отдельный этап после проверки совместимого оборудования и измеренной ошибки; не рисовать выдуманные метры/точки по RSSI.

## Последующая очередь

1. Каталог v2: выразительные действия персонажа; сначала несколько согласованных превью в размере сообщения, затем полный набор. V1 неизменяем.
2. Транскрибация: Linux tests + benchmark действующего VPS на нейтральной записи; включать только при доказанных RAM/времени/health и отдельном решении владельца. Иначе конкретный блокер без покупки инфраструктуры.
3. Места и дневная активность: ложный приход/уход при GPS ошибке, полнота отчёта и архива; корректировки по полю.
4. Защита Room: отдельный безопасный отказ при downgrade, сохранение изолированной базы подтверждено; рабочие приложения не понижать.

Совместные игры, настойчивые уведомления и indoor precision пока предложения; не включать их в текущий выпуск.

## Выполнение

Один этап/результат → адресные проверки → настоящий UI при доступности → evidence/TODO → commit/push. Отдельно source/build/installed/runtime/deployed. Нет телефона/VPS — независимая работа продолжается, непроверенное остаётся[v]. Gradle последовательно штатными скриптами (>=900сек). VPN/профили/данные не менять, обрывы>1мин запрещены. После перерыва продолжать с TODO, а не выбирать очередь заново. Новый выбор нужен лишь при изменении требований или существенном блокере.
