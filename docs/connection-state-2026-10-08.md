# Связь и данные выбранного телефона · 08.10.2026

Этап CW-29/CONNECTION-STATE08.10 расширяет существующее окно «Подробнее» родительского приложения. Главный экран и карта не получают постоянную панель. Используются существующие Material-компоненты, бирюзовая палитра DESIGN, системный шрифт, прокрутка и штатное закрытие HomeDetailSheet; отдельного нового экрана нет. Сохранённый ориентир Family Link из DESIGN_REFERENCES: выбранный человек важнее служебных данных; диагностика раскрывается по запросу.

## Что означает каждый блок

- Соединение этого телефона с сервером — готовность родительского WebSocket именно для текущего сервера. Это не подтверждение присутствия ребёнка или доступности камеры/микрофона.
- Последняя связь выбранного телефона — heartbeat конкретного устройства из текущего канонического семейного каталога, а не другого телефона того же участника. Недавний heartbeat не доказывает работоспособность команды.
- Сведения телефона — время снимка телеметрии; свежесть 3 минуты. Ошибка чтения, сохранённый снимок, отсутствие времени и опережающие часы различаются. Ошибка HTTP не объявляет ребёнка offline.
- Координаты — время измерения выбранного телефона, отдельно от снимка заряда и heartbeat; свежесть 2 минуты. Возвращается из уже существующего чтения FamilyLocationSummary, без дополнительного сетевого опроса. Старая точка не доказывает присутствие человека в том же месте.
- Звук вокруг — пассивный снимок разрешения RECORD_AUDIO и сообщения AudioManager об отключении микрофона. Наличие разрешения не доказывает возможность фонового захвата или состояние privacy toggle. Диагностика не запускает запись и не запрашивает новое разрешение.
- Сеть выбранного телефона — пассивный снимок activeNetwork, системного NET_CAPABILITY_VALIDATED и типа сети. Это не измерение скорости/силы сигнала и не обещание текущей доступности. Старый клиент без новых полей показывает неизвестность.
- Камера и условия геолокации используют прежнюю диагностику; её тексты повторно вычисляются при открытии и регулярном обновлении, чтобы свежесть не застывала.

«Обновить» только читает сведения с сервера. При конкретном отсутствии разрешения/отключённом микрофоне дано действие для взрослого на детском телефоне; скрытого перезапуска мониторинга нет.

## Изоляция и ожидание

Запрос фиксирует сервер, семью, своего участника и свой телефон через Retrofit tag. AuthInterceptor повторно проверяет эту идентичность перед отправкой и обновлением токена; scoped read не запускает перерегистрацию устройства. Сервер получает familyId/actorMemberId через существующий защищённый endpoint статуса. Ответ принимается только при success, точном deviceId и неизменном контексте выбранного человека/устройства. При 401/403 старый снимок скрывается и локальный кэш удаляется.

Кэш хранится через SecureSettingsManager в зашифрованных настройках, без fallback на глобальный снимок. Ключ кэша включает сервер/семью/взрослого/свой телефон/адресата/выбранного участника. Старый кэш только по deviceId для этого окна больше не читается. Смена контекста отменяет запрос и закрывает раскрытое окно с прежним заголовком. Таймаут чтения 12 секунд; повторная кнопка недоступна до окончания. Действующая фоновая частота чтения остаётся 30 секунд; новые проверки свежести не создают дополнительных запросов.

NETWORK-QUALITY08.10 в MetricsManager не исправлялся: этот экран не использует его выдуманный GOOD для Wi-Fi. Новый блок сети сообщает только доступные факты.

## Приёмка

Адресные JVM проверки: разные сроки координат/телеметрии, границы времени, отсутствие/будущие данные, устаревший отказ, отсутствие разрешения/отключение, разрешение без обещания захвата, секунды/миллисекунды и недопустимые числа. Проверка компиляции обоих клиентов выполняется штатным safe runner.

APK, установка, серверная выкладка и включение удалённых функций не входят в этап. Серверные исходники здесь не меняются; используются ранее подготовленные правила доступа endpoint статуса. После выпуска нужен новый снимок детского клиента для микрофона/сети. Android-отрисовка нового интерфейса, крупный шрифт, переходы между людьми, потеря/возврат сети и реальные функции требуют отдельной приёмки установленной сборки; старый установленный экран не является визуальным доказательством этих изменений.
