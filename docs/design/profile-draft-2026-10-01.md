# Восстановление редактора своего профиля · 01.10.2026

## Результат в исходниках

Общий FamilyProfileEditor получает снимок имени, аватара, URI готового кадра и раскрытия пресетов. MainActivity/SettingsActivity обоих клиентов сохраняют его в Bundle и при восстановлении повторно открывают собственный редактор после настройки экрана. Пока семейные данные загружаются, восстановленный Bundle также переносится при следующем пересоздании.

Область черновика — JSON-массив сервер/семья/собственный телефон. Несовпадение отклоняет черновик и удаляет только созданный редактором кадр. Ни имя, ни фото не применяются к другому человеку. Публикация не запускается при восстановлении. Загрузка/публикация, прерванная пересозданием, автоматически не повторяется: результат сетевого запроса может быть неопределённым.

Готовый кадр не удаляется при смене конфигурации или уничтожении для восстановления. Явная отмена и успешное сохранение очищают его. При восстановлении проверяются канонический каталог private cache/profile-crops, имя avatar- и существование файла; исчезнувший файл не используется, выводится сообщение, имя и пресет сохраняются.

## Пределы

Статически просмотрены подписи двух адаптеров, обе точки собственного профиля и четыре пары onCreate/onSaveInstanceState. Сборки и тесты не запускались по режиму проекта; поворот/восстановление процесса на Android ещё не подтверждены. Bundle восстанавливается только если Android ранее сохранил состояние; принудительная остановка приложения не даёт такой гарантии. Android может очистить cache-фото.

Открытый системный выбор фото и ещё незавершённый кадрировщик не восстанавливаются: после возврата доступен редактор с последним готовым выбором. Позиция кадрирования до подтверждения не сохраняется. Повторная загрузка того же кадра после пересоздания возможна; серверный профиль не меняется автоматически.
