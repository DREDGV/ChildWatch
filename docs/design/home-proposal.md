# Главные экраны ParentMonitor и ChildDevice — предложение

01.10.2026. **Согласовано владельцем. Внедрено в Android-исходники; runtime-проверка отложена.** См. [этап внедрения](home-implementation-2026-10-01.md).

[Интерактивный макет](home-proposal.html). Демонстрационные данные, не состояние настоящих телефонов.

## Направление

Уточнение 01.10: переключатель приложения отделён от выбора человека. В ParentMonitor остаются шесть действий; в ChildDevice только чат, сигнал и карта, без прослушки, фото и активности. Профиль ребёнка открывает его редактор; семейная панель ребёнка не предлагает приглашение. Аватары используют точную геометрию Android-каталога (круг 218px, отдельные шаги колонок/строк), поэтому соседние картинки не попадают в круг. Скриншоты: `home-proposal.png`, `home-proposal-child.png`. Браузерная проверка обоих размеров подтверждает отсутствие прокрутки главного экрана.

Выбранный человек — центр экрана. Светлый фон, знакомые бирюзовые акценты и аватары, меньше тяжёлых рамок и повторяющихся заголовков. Компактность достигается компоновкой, а не уменьшением всех элементов.

Опоры из DESIGN_REFERENCES.md: Family Link — человек/состояние/задачи; Apple Family — компактный семейный контур; собственные экраны ChildWatch — пресеты, цвет, роли и список функций. Готовые референсы повторно не исследовались; это развитие существующего экрана.

## Где остаются функции

| Текущая функция | Предлагаемое расположение |
|---|---|
| Выбор человека | Ряд аватаров сверху, видимое кольцо выбора |
| Полный список семьи / приглашение | Кнопка «+», открывающая семейную панель |
| Имя / местоположение / свежесть | Карточка выбранного человека |
| Прослушать, фото, чат, сигнал, карта | Сетка 2×3, все действия видны |
| Активность | Шестая кнопка в сетке; доступ быстрее, чем через диагностику |
| Настройки | Шестерёнка сверху — перенос требует согласования |
| Собственный профиль / редактор / смена профиля | Собственный аватар справа сверху — перенос требует согласования |
| Управление службой родителя | Отдельная компактная строка со switch, без смешения со статусом ребёнка |
| Диагностика / обновление данных | Видимая краткая строка → панель подробностей по нажатию; перенос подробностей требует согласования |
| Проверить обновления / версия | Нижняя строка, всегда на экране |
| Предупреждения о настройке/питании/новом выпуске | Компактная строка состояния с подробностями по нажатию; ни одно предупреждение не удалять |

Диагностика не исчезает: сохраняются зарядка, температура, модель, текущее приложение, свежесть и ручное обновление. В макете основные поля представлены демонстрационно. Служебные дополнительные кнопки и данные существующей диагностики сохранять при переносе.

## Без прокрутки

В браузерном макете проверены 390×844 и компактный 360×740: высота содержимого главного экрана равна доступной, названия/пояснения действий не обрезаются. Шесть действий, служба, диагностика и обновления остаются доступны. Подробности открываются поверх; длинная панель при необходимости прокручивается внутри себя.

Это доказательство **компоновки макета**, не Android-установки. После согласования проверить реальные dp/insets, системный шрифт, длинные имена, большую семью и предупреждения. Не обещать одновременное размещение всех развёрнутых технических данных на любом маленьком экране или при 200% шрифте: адаптацию крупных шрифтов согласовать и не обрезать данные.

## Состояния

Макет переключается: ребёнок на связи / нет связи / взрослый; состояние службы включено/выключено. Взрослому недоступны существующие детские действия, но кнопки остаются видны с пояснением. «Нет связи» показывает возраст последних данных. Выбор роли/функциональные права и сетевые алгоритмы не меняются.

## Что согласовать

Саму визуальную компоновку и перенос настроек/собственного профиля вверх, подробностей диагностики в панель. До ответа владельца не менять Android XML, обработчики, сервер или APK.
