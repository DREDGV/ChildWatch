# Участники и присутствие в чате · 10.10.2026

Состав читается из конкретной разрешённой беседы, а не из семейного подключения к одному ребёнку. Сервер использует существующую каноническую привязку устройства к участнику. Для личного чата список не доступен третьему члену семьи; для группы он не включает всю семью автоматически.

В обоих клиентах строка «В чате: N из M · Участники» открывает общую нижнюю панель. Она показывает имя каждого участника и один из четырёх признаков: «Открыл этот чат», «Устройство на связи», «Нет свежей связи с устройством», «Статус неизвестен». Кнопка закрытия находится отдельно от прокрутки. Настройки группы остаются на прежнем месте. При сетевой ошибке живые статусы очищаются, сохранённые имена явно обозначены как сохранённый состав.

## Контракт

- `GET /api/chat/v2/conversations/:id/presence` — текущий состав и признаки, `actorMemberId`, `observedAt`, `expiresInMs`.
- `POST` по тому же пути: без `sessionId` выдаёт случайный серверный токен; с ним продлевает только собственную сессию этого устройства/участника/чата.
- `DELETE /api/chat/v2/conversations/:id/presence/:sessionId` закрывает только собственный токен. Запоздалое закрытие не затрагивает другую сессию.
- Все операции проверяют действующие права. HTTP ответы `no-store`. Токены чужого устройства/чата нельзя продлить. Отзыв членства исключает участника из ответа и запрещает продление.
- Сессия существует только в памяти процесса. Срок — 45 секунд по монотонному времени сервера; часы телефона/изменение календарных часов не определяют срок. После перезапуска сервера старые токены недействительны.
- Клиент продлевает раз в 15 секунд только в RESUMED. На onPause отменяет наблюдение, очищает статус и пытается закрыть свой токен. При недоставленном закрытии серверный срок остаётся пределом. Внезапная потеря сети может оставить признак до 45 секунд; мгновенное исчезновение не обещается.
- Обновление ограничено 10 секундами, неуспех очищает живой ответ. Ответ старого поколения не публикуется после выхода/смены экрана. Сервер, семья, свой участник и устройство проверяются относительно захваченного контекста репозитория.
- Признак открытого чата не является подтверждением прочтения конкретного сообщения. Подтверждения прочтения продолжают использовать существующий механизм отдельно.
- История посещений и «был в сети вчера» не добавлены: достоверного источника такого времени в старом endpoint нет. Время привязки телефона не выдаётся за время последнего присутствия.
- Сервер ограничивает активные токены: 8 на устройство, 10000 на процесс; истечение освобождает лимит. Несколько телефонов одного участника объединяются по каноническому memberId.
