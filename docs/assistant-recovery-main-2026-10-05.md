# Штатная настройка восстановления — 7.4.287

CW-01/FIELD-REPEAT, 05.10.2026. Владелец разрешил перенос подтверждённого assistant-пилота в обычную настройку.

## Реализовано

SettingsActivity → разрешения → «Работа после перезагрузки». Экран объясняет однократный выбор, доступ родителя к звуку/фото, уведомления/индикаторы, неизменность рабочего стола и границы подтверждённого результата. Статус различает фактически выбранного Android-помощника, начатую настройку и отключённое восстановление; отдельно сообщает, если мониторинг выключен. Предусмотрены возврат к прежнему помощнику, отключение после системного возврата и закрытие.

FamilyAssistantService/Session, FamilyRecognitionService, экран настройки и metadata перенесены в main. Службы по умолчанию выключены; пользовательская кнопка включает кандидата и открывает проверенный на Moto Settings.ACTION_VOICE_INPUT_SETTINGS. onReady запускает обычные службы только при сохранённом opt-in, собственном effective context и включённом мониторинге, не открывает Activity/chooser и не начинает запись. FamilyRecognitionService делегирует явный speech-запрос установленному движку только при выбранном помощнике.

Сохранены прежние полные ComponentName и ключ opt-in: уже выбранный Test Moto 286 не должен терять роль только из-за переноса source set. Это source-level совместимость; upgrade с сохранением роли на физическом телефоне ещё требуется. Название пакета `.debug` у этих классов сохранено ради совместимости ComponentName, а не из-за зависимости release от debug исходников. AssistantRecoveryAccess больше не ограничен BuildConfig.DEBUG и всегда проверяет действительный системный выбор.

Пробная запись отделена в debug AssistantLabVoiceService; capture probe и Home-пилот исключены из release manifest. Production service не ссылается на них. Сценарий изолированного эмулятора обновлён на lab subclass; после переноса он не запускался заново, только синтаксис проверен. Production распознавание речи отдельно не испытано.
