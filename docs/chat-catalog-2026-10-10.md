# Чат: собственный каталог и GIF · 10.10.2026

## Результат исходников

В обоих приложениях существующее меню вложений дополнено собственным каталогом и выбором GIF с телефона. Стандартная панель эмодзи сохранена. Каталог имеет вкладки «Стикеры» / «GIF», подписи, загрузку, повтор, прокрутку и закрытие. Выбор создаёт обычный локальный media-черновик; отдельное «Отправить» запускает прежнюю очередь с устойчивым clientMessageId. Новая версия Room не нужна: STICKER/GIF используют уже существующие поля метаданных и вложений версии14.

Стикеры — прозрачные PNG, GIF — реальные многокадровые файлы. Общий Glide-контроллер показывает анимацию только у видимых сообщений, останавливает её при уходе в фон, отсоединении/переработке ячейки и выключении настройки. Учтена системная настройка отключения анимации. Личные файлы не помещаются в общий Glide disk/memory cache; временный скачанный файл удаляется после завершения декодирования. Ограничение GIF-предпросмотра: 10МиБ, сторона≤1024px,≤120 кадров, суммарный canvas≤32Мп; превышение оставляет возможность сохранить файл.

## Каталог и доступ

`GET /api/chat/v2/conversations/:id/media-catalog` возвращает version и проверенные id/label/type/MIME/sizeBytes/SHA256/filename/256×256. Контент получается через `.../media-catalog/:version/:itemId/content` с текущими правами беседы. Публичных ссылок, внешнего поиска или передачи данных Giphy/Tenor нет. Каталог не копирует личные файлы других бесед.

Сервер сверяет размер, контрольную сумму, формат, размер изображения и безопасный путь, ограничивает manifest64КиБ/ресурс1МиБ. Повторная проверка членства выполняется после чтения контента. Capability mediaCatalog включается только при наличии целого валидного набора. Клиент сверяет bytes/hash/декодированный MIME/dimensions, привязывает private cache к server/family/member/device/conversation. Offline допускается до24ч только при транспортной ошибке;401/403 очищают соответствующий scope.

Каталог v1 ещё не опубликован. Первый плоский прототип отклонён владельцем; рабочие картинки заменяются до первого выпуска. После публикации уже выпущенные версии и их байты должны оставаться неизменными; новый набор выпускается с новой версией.

## Иллюстрации

Оригинальный персонаж — мятный объёмный дракончик с кремовым животиком и персиковыми акцентами.12 поз: привет, объятие, любовь, скучаю, дома, в пути, забери меня, всё хорошо, спасибо, супер, спокойной ночи, давай играть. Для небольших GIF используются плавные покачивание/пульсация готовых поз. Это две простые анимации, не покадровая актёрская анимация персонажа.

Встроенный imagegen использован для создания каждой оригинальной иллюстрации; prompt set/provenance находятся рядом с manifest. `scripts/import-chat-catalog.py` выполняет экспорт с сохранением alpha в256px и кодирование GIF, затем пересчитывает manifest. Полноразмерные исходники сохранены локально в `.runtime/chat-catalog-modern-originals`; рабочие ресурсы проекта — `server/assets/chat-catalog/v1/`. Не использовать отклонённый векторный прототип для перегенерации рабочего набора.

## Проверка и границы

Review исправил отмену после фактического Room insert: короткий commit/ACK завершается, файл durable-черновика сохраняется; отмена до insert удаляет только неподтверждённую копию. Shared cancellation checks3/3 проходят, включая отмену между commit и ACK. Ошибка прикрепления больше не стирается последующим busy(false); вся панель прокручивается одним ограниченным по высоте контейнером.

Подтверждено: server16/16, shared catalog3/3, commit cancellation3/3, GIF7/7 (заново на финальных ресурсах), real catalog14items/1378262байта; оба клиента+Android-test-source compile PASS2м15с. Логи `.runtime/chat-catalog-server-modern-2026-10-10.log`, `.runtime/chat-catalog-2026-10-10-reviewed.log`, `.runtime/chat-catalog-modern-gif-2026-10-10.log`. Исходники/локальные тесты/компиляция не доказывают отображение и доставку на установленных телефонах. APK не собирались, установка и VPS-публикация не выполнялись. Для native-приёмки нужны согласованный upgrade и актуальный server capability, затем личная/групповая беседа, sticker/GIF/телефонный GIF, large font/landscape, выключение анимации, scroll/pause, offline retry/restart и отзыв доступа.

Сначала выпустить общую основу вложений из `docs/chat-attachments-2026-10-10.md`; транскрибация из `docs/chat-transcription-2026-10-10.md` — отдельная capability и не должна включаться автоматически. Текущий этап добавляет:

- изменённые `services/ChatAttachmentStore.js`, `services/ChatConversationService.js`, `routes/chat-v2.js`, `routes/chat-attachments.js`;
- весь `assets/chat-catalog/v1/` с manifest и14 ресурсами (manifest последним).

Не экспонировать assets через public static middleware. До рестарта проверить syntax и7 catalog tests+9 attachment tests, затем authenticated capabilities/list/content,403 для чужой беседы и совпадение SHA. Сервер выпускается первым, затем подписанные обновления обоих приложений с сохранением данных; отсутствие capability скрывает новые действия на старом сервере. Этот документ описывает точный состав source-этапа, не подтверждает выкладку.
