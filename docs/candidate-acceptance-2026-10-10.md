# Кандидат ChildWatch: программа приёмки

Состав: последние исправления GIF/меню и участников + существующая карта/скорость/follow. Окружение не расширяется, каталог v1 неизменен, ASR OFF. Текущая готовность и шаг возобновления находятся в CW-14/CANDIDATE-CYCLE10.10 в TODO.md.

## До замены рабочих приложений

1. Сверить публичный manifest, локальный номер/резервации и живые версии двух аппаратов. Package родителя ru.example.childwatch; рабочего ребёнка ru.example.parentwatch.debug. Не устанавливать другой вариант параллельно как «обновление».
2. Сверить cert SHA с опубликованными308; оба APK имеют один новый versionCode, превосходящий опубликованные/установленные. Подпись не менять ради установки. Нет телефона — installed-version gate остаётся открытым.
3. Проверить локальные shared/design policies, server chat/presence/location/attention tests и компиляцию Android test source. Linux-only ASR tests на Windows остаются SKIP; это не разрешение включить ASR.
4. Isolated native tests: панели файлов/эмоций/участников, реально меняющиеся кадры GIF/stop/revoke/clear, контраст/закрытие и крупный шрифт. Test APK отдельно от основных; после испытания удалить только instrumentation package. Не менять глобальную настройку шрифта рабочего аппарата без решения владельца; тестовое Context configuration можно увеличить изолированно.

## После согласованной установки поверх текущих приложений

| Сценарий | Наблюдаемый результат |
|---|---|
| Открыть существующую GIF | Анимация видна при включённой настройке; прозрачный фон, целая картинка, без filename/size/open chrome; время/имя читаемы |
| Смайл/скрепка/черновик | Эмоции отдельно от Фото/Аудио/Документ; preview до отправки; cancel/close/back понятны; уход в фон закрывает панели и останавливает движение |
| Изображение/файл/голос | Отправка/скачивание/прослушивание у адресата; offline/retry/restart создаёт одно сообщение; ошибки не теряют черновик |
| Группа на паре | Полный серверный состав; четыре разных статуса; второй телефон в этом чате/в другой беседе/в фоне; read receipt отдельно |
| Потеря присутствия | Ошибка обновления убирает live claims; невыданное закрытие не оставляет «Открыл чат» дольше45сек; восстановление создаёт/продлевает свой токен |
| Карта | Аватар заметно движется по принятым точкам; скорость рядом; pan приостанавливает follow, одна кнопка возвращает; другой человек/история/фон не наследуют движение |
| Стоянка/ходьба/поездка | Сохраняется фактическое measured/estimated/unknown, error/accuracy/возраст; нет выдуманного нуля; после45сек текущая скорость скрыта |
| Звук/фото | Reboot после обычной разблокировки не теряет подтверждённую настройку восстановления; короткий сетевой переход не ломает последующий запрос |
| Сигнал | Один согласованный запрос на точном адресате: родитель→server→DELIVERED→STARTED/FAILED→родитель, явный STOP; ожидание UI не подтверждение запуска |

Сообщения и команды в рабочую семью не запускать автоматически ради проверки: владелец выполняет контролируемые действия или отдельно разрешает один тест. Не создавать заново семью/профили и не выходить из рабочей привязки. Обрыв>1мин запрещён.

## Свидетельства об отказе

Сразу сохранить время с часовым поясом, версию каждого телефона, выбранного человека/устройство, requestId/clientMessageId, режим сети, состояние приложения и последний видимый статус. Отдельно фиксировать принятие сервером, доставку ребёнку, запуск операции, upload/result и отображение родителем. Наличие socket-connect или доставки команды не равняется успешному снимку/звуку/сигналу.

Релевантные журналы и screenshots только в приватной `.runtime`, без паролей/токенов, не коммитить полные семейные беседы/фото. Если журнал вытеснен, не угадывать причину; один согласованный повтор и новая временная шкала.

## Выпуск

Перед выкладкой консистентный backup действующей SQLite, приватных вложений и кода; проверить текущую основу сервера и SHA пакета. Сервер presence update первым, signed clients вторыми. Для OTA: APK доступны и скачиваются с правильными SHA/size до атомарной замены manifest. Старые308 файлы сохраняются. Никакого APK downgrade/-d; откат сервера отдельно, исправление клиента новым большим кодом. Не считать подготовленный пакет опубликованным или полевые сценарии закрытыми.
