# ChildWatch7.4.291 — публикация подготовленных APK

Владелец разрешил публикацию обновления для остальных телефонов07.10.2026. Два локально собранных APK подписаны постоянным сертификатом и проверены по metadata/hash/size. Parent7.4.291, child7.4.291-debug, оба code2000000291. SSH из текущей сессии завершился таймаутом; серверный каталог владелец видит как277. Публикация пока НЕ подтверждена.

Для другого агента: выполнять при доступном сервере без VPN. Никаких новых сборок/номеров: использовать только APK+manifest из этой папки. scripts/release-updates.ps1 без PreflightOnly пересобирает приложения — для этой подготовленной291 его НЕ запускать.

1. Прочитать действующий /updates/manifest через сервер localhost3000. Сверить оба packageName/certificate и что291 новее каждой опубликованной версии; guard scripts/update-version-guard.ps1. Если сервер уже имеет>=291, остановиться и выяснить состояние. Сверить SHA256SUMS этого комплекта.
2. Проверить реальный CW_UPDATE_DIR и права. Сохранить прежний manifest вне публичного переключения. Подготовить /tmp/cw-updates-in без удаления чужого содержимого; загрузить туда три файла: оба APK и manifest.json. Сверить на сервере размер/SHA256. Уже существующие APK других версий не удалять.
3. publish-updates.sh — сохранённый штатный publisher: lock, повторное сравнение версии/подписи, APK сначала, атомарная замена manifest последней. Проверить, что DIR соответствует реальной serving directory, и выполнить этот скрипт на сервере с нужными правами. Скрипт ожидает подготовленные файлы в /tmp/cw-updates-in, по умолчанию публикует /var/www/childwatch-updates, chown adminuser:adminuser. Не угадывать DIR при другой конфигурации.
4. Прочитать публичный /updates/manifest и скачать ОБА /updates/files/<имя из manifest>. Сверить versionCode/package/cert/size/SHA256 с комплектом. Сама запись файлов не доказательство публичной выдачи. Затем на другом семейном телефоне проверить обновление через приложение.

OTA не требует перезапуска Node-службы, если serving directory уже настроена. Не менять базу/аккаунты/привязки/разрешения/VPN автоматически. Для батареи на карте отдельно server-map-battery-2026-10-07.zip (два JS), для network/watchdog серверный код обновлять не нужно. Возврат прежнего manifest допустим при ошибке публикации; уже установленные291 Android не откатит обычной установкой.
