## Проверка владельцем

После обновления серверного кода и обоих приложений:

1. «Подробнее»: выбранный ребёнок, возраст телеметрии и координат, отсутствие противоречивых подписи/батареи при переключении человека.
2. Карта: выбрать ребёнка → «Следить»; журнал места, вход/выход из зоны без ложного ухода при неточном GPS. Первое подтверждение и реальные поездки требуют времени.
3. Активность: сегодняшний и доступные прошлые дни; отсутствие истории объясняется явно. Старые дни автоматически не появятся, если Android их не предоставил.
4. «Сигнал»: успех, отсутствие связи и повторное открытие окна; нет бесконечного ожидания/автоматического повторного звука. Полный перезапуск процесса не заявлен как восстановление незавершённого запроса.
5. Прослушка и фото: обычное включение, повторное включение после смены сети и перезагрузки. По прежнему ограничению обрыв дольше минуты сейчас не нужен. Указывать время и выбранный телефон при отказе.
