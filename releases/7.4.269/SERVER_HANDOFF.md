# Сервер для APK 7.4.269

Комплект server-source-7.4.269.zip содержит текущие серверные JS/CJS, package.json/lock. Нет ключей, .env, БД, загрузок, журналов, node_modules. Не заменять каталог сервера целиком: сохранить рабочие secrets, БД, uploads и process configuration. Сверить server-source-inventory.json с установленным кодом. Этот комплект локальный, не опубликован.

## Выкладка другим агентом

1. Сохранить резервную копию кода и БД; определить реально запущенный index.js/процесс. Сопоставить текущий сервер и комплект; проверить локальные серверные изменения, не перетирать их вслепую.
2. Обновить код приложения и новые модули. Установить зависимости по lock при необходимости; сохранить .env/keys/uploads/БД. Node --check для затронутых файлов.
3. Перезапустить только процесс ChildWatch. Проверить старт без ошибок и HTTP после выкладки.
4. Ключевые новые контракты: /api/photo/readiness/:deviceId; HTTP результат/квитанции фото через PhotoDeliveryStore; family live/trail с speedMps/speedAccuracyMps и deviceId истории; LocationMotionStore; семейные места/события; строгие AUDIO_LISTENING/REMOTE_PHOTO и адресат без подмены единственным ребёнком; актуальные family onboarding/profile/chat endpoints.
5. APK и manifest публиковать только после успешной выкладки, сначала APK, затем manifest. Пакет ребёнка ru.example.parentwatch.debug сохранён специально для обновления поверх прежнего. APK-подпись/хеши должны совпасть с локальным manifest.

Измеренная скорость требует новых обоих APK и этого сервера. Прежний сервер не доказывает работу новых фото/мест/скорости. После выкладки записать время, процесс, подтверждённые ответы и хеши установленного кода; не утверждать полевой успех по одному старту.
