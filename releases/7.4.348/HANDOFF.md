# ChildWatch 7.4.348: готово к обновлению сервера

Владелец поручает серверную выкладку отдельному агенту. Сервер можно обновлять сейчас. Локальная пара подписана и проверена; установка поверх333 выполняется после успешной серверной выкладки.

## Передать серверному агенту

Применить `server-patch.zip` по `server-patch/README-DEPLOY.md`: девять runtime файлов для Морского боя, Змейки и Арканоида; точечно интегрировать index.js, обязательный authenticated namespace, один Node worker. Восемь reference файлов не копировать поверх действующего кода вслепую. Сначала backup и проверки совместимости. Базу/семейные данные/ключи/VPN не менять, транскрибацию не включать.

Архивы находятся рядом с этим файлом:

- `server-patch.zip`, SHA256 `4a3aa77f5beb049b78da7c295e2de2ad69b0eed934cbed7a2edf226729c67292`.
- `ota.zip`, SHA256 `0d3805d170ad672aa4429ab2793a78ec24b7fa05d8fcd6c493493d5300e4f7a1`.

После выкладки проверить health,401 без токена, отклонение Socket.IO handshake без токена и capabilities с действующей семейной авторизацией. Вернуть владельцу журнал, фактический результат и текущую OTA-версию. Основной агент затем обновит подключённые телефоны. OTA публиковать после проверки сервера: APK сначала, manifest последним, затем скачать и сравнить SHA. Если сервер не проходит проверки, OTA не публиковать.

## Приёмка после установки

1. Каталог «Игры»: все три игры, одиночная партия без сети, выход/возврат.
2. Морской бой: приглашение/принятие, два флота, ход, скрытые чужие корабли.
3. Змейка: общая еда/траектории/очки, собственное управление, пауза/готовность.
4. Арканоид: каждый видит свою платформу снизу, один мяч/общие блоки и жизни; пауза/возврат и готовность обоих.
5. Сохранность рабочих чатов, карты, звука и фото. Обрывы дольше минуты не проводить.

Компиляция/подписи/пакеты подтверждены. Парная игра рабочих профилей через VPS и мобильную сеть остаётся проверкой после выкладки; изолированные нативные проверки не подменяют её.
