# Возврат доступа только запасному Test Moto

Для владельца сервера. Это действие с данными, а не выкладка новой версии сервера. SSH из текущей сессии к 31.28.27.96:22 завершился таймаутом; на работающем сервере ничего не менялось.

Запасной Moto ZY227XB3PV использует сохранённый идентификатор ChildDevice, сверенный после reboot и на установленной 283. Сервер отвергает его регистрацию: HTTP 403 `DEVICE_REVOKED`. Токены/проверка приглашения возвращают 401. Смена идентификатора вместо восстановления доступа не выполнялась. Приглашение Test Moto пока не принято.

Скрипт содержит **один заранее проверенный ID этого запасного аппарата**. Без `--apply` он только показывает состояние. С `--apply` администратор явно возвращает этому ID право зарегистрироваться, меняя одну строку `devices.is_active` с 0 на 1. Старые семейные привязки и связи не включаются. После этого потребуется свежее обычное родительское приглашение.

Скопировать `restore_test_moto.py` на сервер. Указать точный путь существующей рабочей базы (тот же, по которому проверяли integrity и количество сообщений):

```sh
python3 restore_test_moto.py /полный/путь/data/childwatch.db
```

Проверить имя аппарата, `isActive: 0`, `activeFamilyBindings: 0`, `activeLinks: 0`. Если владелец сервера действительно возвращает доступ этому тестовому аппарату:

```sh
python3 restore_test_moto.py /полный/путь/data/childwatch.db --apply
```

Защита: база должна уже существовать; должен быть ровно один такой аппарат; при активной семейной привязке/связи скрипт прекращает работу. Перед изменением выполняется quick_check и полноценный SQLite backup рядом с базой. Транзакция повторно сверяет исходное состояние и требует ровно одну изменённую строку; состав семьи, связи и число сообщений проверяются. Старые токены не воскрешаются. Вывод содержит путь резервной копии и `changedRows: 1`. Серверная логика проверки отзыва доступа читает БД; выкладка кода/отключение защиты не нужны.

Проверки на отдельных локальных SQLite fixtures PASS: режим чтения не меняет доступ; восстановлен только заданный аппарат, другой отозванный аппарат/чат сохранены и backup создан; аппарат с активной привязкой отклонён без изменения. Эти проверки не являются запуском на рабочей серверной БД.

После возврата доступа подключить Moto к семье свежим приглашением Test Moto/Ребёнок. Затем повторить reboot → unlock → Home → погашенный экран → звук/фото/карта. Текущий статус находится в TODO, CW-01/FIELD-REPEAT.
