# ChildWatch: заряд на семейной карте — 07.10.2026

Комплект нужен для отображения заряда выбранного телефона в семейной карте клиентов290/291. Для автоматического восстановления соединения в291 обновление сервера НЕ требуется: используется существующий ping/pong.

Выкладку выполняет отдельный агент по разрешению владельца, без VPN. Этот комплект не переключает VPN, не подключается к серверу и не публикует OTA.

Содержит ровно два JS: server/routes/location.js и server/services/FamilyBatterySnapshot.js. Первый заменить, второй добавить в соответствующий каталог работающего Node-приложения (префикс server/ убрать). Без новых зависимостей, миграций и замены базы/конфигурации. Поле battery добавляется к /api/location/family/latest после проверок членства и LOCATION; ошибки optional telemetry не скрывают GPS.

Перед заменой сверить действующий location.js с комплектом: сохранить серверные изменения другого агента, если файл отличается не только этой правкой. Сделать резервную копию обоих кодовых файлов; сверить SHA256SUMS. node --check обоим, затем штатный перезапуск службы. Проверить журнал запуска/health. Без авторизации endpoint должен отклонять запрос; с авторизацией семьи — battery точного выбранного deviceId, уровень0..100 и отдельное время замера. Не публиковать чужой статус при запрете LOCATION. При проблеме вернуть прежний location.js и прежний helper, если он существовал, штатно перезапустить. Базу не трогать.

Локальная проверка: family-battery.node.cjs3 tests и прежние location access14 tests PASS (TODO CW-06/BATTERY-CONSISTENCY07.10). Это не доказательство развёрнутого сервера. Клиенты совместимы с прежним сервером: пока батарея на карте может быть неизвестна, домашняя карточка сохраняет свой источник.

APK и manifest не включены; OTA публикация — отдельное действие. После выкладки сравнить заряд/дату на главном экране и карте для одного выбранного телефона.
