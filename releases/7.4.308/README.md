## Порядок обновления

1. Оператор сверяет фактическую основу VPS с серверной инструкцией, сохраняет согласованный backup кода, SQLite и private blobs. Разворачивает серверный пакет с `CHAT_TRANSCRIPTION_ENABLED=0`; проверяет health, права бесед, capabilities и содержимое каталога. Новых npm dependencies нет; локальную базу/.env не переносить.
2. С разрешённой беседой проверяет image/file/voice upload→send→download, повтор без дубликата и отказ чужому участнику. ASR остаётся выключенным: Linux guard и benchmark памяти/задержки на реальном сервере ещё не выполнены.
3. Проверяет актуальный публичный manifest повторно. Если там уже такой же или больший номер либо другая подпись/package — остановить публикацию308. Загружает APK из `ota/` первыми, проверяет публичные hash/size, затем заменяет manifest атомарно последним. Подробности в `ota/README-OTA.md`.
4. Остальные телефоны обновляются поверх текущих приложений. Не удалять приложения и не применять `pm install -d`: обе базы Room14 имеют destructive downgrade fallback. Откат сервера и исправление клиента большим номером — разные процедуры; принудительное APK-понижение может очистить базу.

## Короткие полевые проверки после выкладки

1. Стоянка/ходьба/повороты: подпись скорости или честная неизвестность, возраст данных, заметный переход аватара, «Следить» и пауза от ручного сдвига. Сохранить сопоставимый маршрут для оценки ошибки скорости.
2. Изображение, оригинал как файл и голос: отправка, предпросмотр/прослушивание, скачивание, отмена и повтор после краткого отсутствия сети; ровно одно сообщение. Старые сообщения остаются доступны.
3. Собственные стикеры/GIF у обоих участников и отключение анимации. Отзыв доступа к беседе закрывает вложения.
4. Локальное окружение на согласованных Android11/14: известные AP/BLE, выключенное радио, отказ разрешения, stale/empty и погашенный экран. Удалённая панель окружения ещё не реализована.
5. Обычные звук/фото после обновления; новый отказ связывать с конкретной командой и журналами. В этом этапе их новый end-to-end тест не выполнялся; обрывы дольше минуты не запускать.
