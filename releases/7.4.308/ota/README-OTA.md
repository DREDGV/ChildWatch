# OTA 7.4.308

Это готовые фиксированные APK, уже установленные по USB на рабочей паре. Публичный OTA в момент подготовки10.10.2026 остаётся296; локальный updates/ не означает публикацию.

Сначала обновить сервер по server-patch/README-DEPLOY.md соседнего комплекта и проверить capabilities. Распознавание на сервере оставить выключенным. Удалённое окружение не включено; в ребёнке есть только добровольная локальная проверка.

Перед публикацией снова прочитать действующий manifest и применить scripts/update-version-guard.ps1: обе записи308 должны быть новее публичных, с теми же package и сертификатом. Если уже опубликован308/больше, этот manifest не заменять. Сверить APK с SHA256SUMS.txt, manifest.sizeBytes и manifest.sha256; подпись сертификата сохранена.

Сохранить прежний manifest. Сначала загрузить оба APK рядом с прежними файлами, не удаляя их; скачать новые публичные APK и сверить размер/SHA. Только затем заменить manifest.json атомарно. README/SHA являются служебными файлами и приложению не нужны. Не публиковать server/private-data или исходники как общедоступные ресурсы.

Установка поверх текущего приложения сохраняет данные. Не применять APK downgrade/-d и не удалять приложение: обе базы Room14 могут очиститься при принудительном понижении. Серверный rollback отдельно, исправление клиента — большим versionCode. Не использовать общий release-updates для повторной сборки308: новая сборка получает следующий номер; этот комплект публикуется готовым.
