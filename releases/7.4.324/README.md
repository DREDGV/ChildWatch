# ChildWatch 7.4.324

Окончательная локальная пара: полный экран «Игры» → Арканоид. Обновляет319/323 поверх, без сброса данных.

Общая кнопка на главной; выбор теперь в отдельной Activity с возвратом и прокруткой. Арканоид пока одиночный, без сети. Совместные игры остаются отдельным этапом.

Сервер для этой правки не требуется. Семейный API крестиков-ноликов ранее подготовлен отдельно и этой сборкой не используется. OTA не опубликована; manifest здесь только для подготовленной пары.

## Проверка владельцем

Открыть «Игры» с главной → Арканоид → запуск; поводить платформу пальцем, проверить паузу/уход в фон/возврат. «Назад» из партии возвращает каталог, «Назад» из каталога — главный экран. Совместной партии в этой версии пока нет.
