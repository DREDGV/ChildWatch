# Сервер ChildWatch — комплект 03.10.2026

Комплект исправляет общий лимит запросов карты/камеры и добавляет серверную часть «Забери меня» вместе с подготовленной выдачей истории карты. Содержит ровно шесть JS-файлов, без базы, ключей, настроек, uploads и node_modules. Новые зависимости npm не нужны.

1. Перед заменой сохранить прежние файлы и согласованный снимок рабочей SQLite через backup API/SQLite .backup. Не копировать открытую БД как обычный файл.
2. Распаковать архив в отдельную временную папку. Каталог server/ внутри соответствует корню работающего Node-приложения: префикс server/ убрать, остальные относительные пути сохранить. SHA256SUMS.txt позволяет сверить файлы.
3. Проверить каждый из шести файлов через node --check. Затем заменить файлы, перезапустить штатную службу и проверить её журнал/health. При сбое вернуть прежние файлы и перезапустить службу; рабочую БД не заменять этим архивом.
4. На авторизованном родительском телефоне проверить готовность камеры после обновлений карты: они больше не должны расходовать один бюджет. Проверить фото отдельно и со звуком. Для «Забери меня» нужны оба новых клиента и авторизованная проверка /api/pickups.

Проверено локально: синтаксис шести файлов; rate-limit-isolation.node.cjs PASS; 7 тестов auth и 18 тестов photo routing/deadline/delivery PASS. Это не проверка развёрнутого сервера. Семейный pickup SQLite smoke прошёл ранее (полномочия фикстурные).

Первоначальный отказ фото ещё не объяснён: родитель отправил команду, но результата не получил; позже зафиксирован HTTP 429. Заряд 1% не доказан как причина. Реальная одновременность камеры/микрофона требует проверки обоих телефонов. Публикация нормального APK/OTA отложена владельцем до исправления новых ошибок.

Сервер владелец обновляет вручную. Этот комплект не публикует APK и не переключает OTA manifest. Старый комплект releases/7.4.278/server-source-7.4.278.zip не включает исправление AuthMiddleware; использовать новый архив server-fixes-2026-10-03.zip.
