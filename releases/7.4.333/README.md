## Приёмка

На обоих основных APK проверены главная → каталог → расстановка → Флот готов → Ваш ход, снимки просмотрены. Семейная сетевая партия, приглашения и восстановление через VPS не проверены. После серверного обновления: приглашение/принятие, расстановка обоих флотов, выстрел/промах/смена хода, выход и возврат. Обрыв не более минуты; повтор отправки не создаёт второй ход. Доказательства и текущий resume находятся в TODO.md.
