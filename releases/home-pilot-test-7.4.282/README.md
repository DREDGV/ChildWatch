# ChildDevice 7.4.282 — добровольный Home-пилот

Проверочный debug APK, versionCode 2000000282, package `ru.example.parentwatch.debug`. Не OTA и не обычный выпуск. Собран и установлен поверх 7.4.280 на запасной Moto ZY227XB3PV 05.10.2026.

SHA256 APK: `9c630a93686c2d9d7a89be1dab0a61572097c3c519ab584c5f4e32a1ae442838`.

После обычной установки Home-кандидат и настройка пилота выключены. На этом запасном аппарате включён только компонент `HomePilotControlActivity` и открыт экран подключения. Домашний экран Moto не назначается/не меняется установкой. Владелец выбирает ChildWatch кнопкой подключения через обычные настройки Android.

Возврат: «Настройка и возврат домашнего экрана» → «Вернуть прежний домашний экран» → выбрать исходный Motorola launcher в Android. После этого «Отключить проверочный режим» выключает Home-кандидат. Пока ChildWatch остаётся выбранным Home, приложение не отключает его само.

Автоматический захват звука/фото эмуляторного probe на реальном аппарате запрещён guard. Используются обычные родительские команды и сохранённая семейная сессия. Мониторинг, выключенный пользователем, не включается автоматически.

Сценарий/ограничения: [отчёт пилота](../../docs/boot-capture-home-pilot-2026-10-05.md). Текущий статус: TODO, CW-01/FIELD-REPEAT. Установка и экран подключения проверены; reboot и реальная доставка ещё не подтверждены. Первое обычное разблокирование после reboot остаётся обязательной границей.
