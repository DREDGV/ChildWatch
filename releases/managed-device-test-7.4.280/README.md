# Проверка управляемого ChildDevice 7.4.280-debug

Только запасной тестовый телефон ZY227XB3PV, не OTA и не нормальный выпуск. APK собран с проектной подписью. Манифест подтверждает versionCode 2000000280. Работа device owner/reboot/audio/photo ещё не проверена.

Включена регистрация DPC и проверка фактического device-owner статуса; обычная установка не назначает владельца устройства и не снимает запрет Android. Инструкция/границы: ../../docs/boot-capture-managed-device-2026-10-03.md. Предварительно требуются решение владельца о сохранении/очистке данных запасного телефона и его подготовка без аккаунтов/другого управляющего приложения. На осмотренном запасном Moto девять аккаунтов: ничего не удалено.

После согласованной подготовки: установить через scripts/build-and-install.ps1 с явным ConnectedChildSerial ZY227XB3PV; отдельно назначить device owner системным provisioning. Компонент ru.example.parentwatch.debug/ru.example.parentwatch.management.ChildDeviceAdminReceiver. Никогда не применять к рабочему ZY227XB2QD с Family Link. Назначение не выполняет pairing и не выдаёт CAMERA/RECORD_AUDIO — их настроить при первичном запуске.

Приёмка: перезагрузка, обычное разблокирование, без открытия ChildDevice — свежие карта/чат, поток звука, снимок и одновременность фото/звука. До первого разблокирования зашифрованное хранилище остаётся отдельным ограничением. Не считать устройство готовым по одному owner=true.
