# ChildWatch Home experiment — 7.4.281-debug

Только изолированная проверка Android; не обычный выпуск и не OTA. Установлено только на ChildWatchHomeTest / emulator-5582. Аккаунты и домашние экраны физических телефонов не менялись.

Версия: `2000000281`, `7.4.281-debug`, package `ru.example.parentwatch.debug`, постоянная подпись проекта. SHA256 в SHA256SUMS.txt.

Home/проверочные receiver выключены по умолчанию, код дополнительно допускает только изолированную localhost-сессию на эмуляторе без device owner. Прототип показывает приложения и ChildWatch; назначение Home на телефоне не разрешено этим комплектом.

После реального reboot/появления настоящего Home/ухода в Settings/погашения экрана: AudioRecord не silenced, JPEG получен. Серверная доставка и реальные Moto не проверены. Полные границы и свидетельства: [отчёт](../../docs/boot-capture-home-probe-2026-10-04.md). Не обещать полный доступ до первого разблокирования.
